# B｜校园互助与结果跟进

负责人为 [`aserssi`](https://github.com/aserssi)。本文梳理五条功能故事，覆盖发起者、回应者和拾到物品的同学，串起「发布 → 回应 → 查看进展 → 发起者确认结果」。问题收到回复后显示「已有回应」。发起者确认事情解决后才显示「已解决」。

## 公开资料观察

查阅日期为 2026-11-23。下列记录来自同济大学公开资料，供定位角色、现行流程和待验证的需求。需求状态为**待真人访谈和组内确认**。

### OBS-B01 朋辈答疑

同济团委发布的「数学外卖」年度报告记录了学生在按课程组织的 QQ、微信群求助，由朋辈讲师等参与答疑。报告也提出继续改善助学进展跟踪。这个案例支持记录问题所属课程和让答复关联原问题。尚需核实同学在现有群聊里怎样找回自己的答复、是否愿意在新渠道再次提问。 [「数学外卖」2025 年度总结报告](https://youth.tongji.edu.cn/info/1010/3067.htm)

### OBS-B02 求助表达

校医院公开的活动记录显示，参加者练习交代遇到的问题、产生的影响和希望得到的支持，也讨论了发出求助后未获回应的情况。这个案例支持在发布时写清背景和所需帮助。活动记录未提供学生使用校园互助应用的反馈。 [同济校医院的求助表达与支持资源讲座记录](https://shtjh.tongji.edu.cn/info/1163/4216.htm)

### OBS-B03 进度和结果反馈

同济新闻网记录了嘉定校区学生代表提出校园生活问题后，校方在后续座谈中分别反馈已办结、办理中和仍需论证的事项。这个案例支持把「收到回应」与「事情已解决」分开呈现。让互助发起者自己确认解决是校圈的候选设计，需用学生近期的求助经历复核。 [嘉定校区学生座谈处理进展记录](https://news.tongji.edu.cn/info/1002/6126.htm)

### OBS-B04 失物信息和认领

学生会活动记录有同学从他人获知领取地点和时间后成功认领遗失钱包的实例。保卫处现有官网也提供失物招领入口。历史案例支持公开可辨识的物品线索与领取途径。具体发布字段和哪些物品特征应留给当面核对，需向学生或招领人员确认。 [学生会失物招领活动记录](https://www.tongji.edu.cn/info/1033/13065.htm) · [同济保卫处失物招领入口](https://baowei.tongji.edu.cn/3063/list.htm)

## 用户故事

### B-01｜发布学习或生活求助

作为遇到学习或校园生活困难的本校学生，我想说明问题背景和希望得到的帮助，以便同学判断能否给出有针对性的回应。

- Given：我已登录校圈，准备发布一条学习求助或生活咨询。
- When：我选择相应类别，填写标题、问题背景与所需帮助并发布。
- Then：互助列表新增一条帖子，详情显示所填内容和「待回应」，回复数为 0。若缺少所需帮助，提交时提示补全，该次提交不创建帖子。

调研证据：[OBS-B01 朋辈答疑](https://youth.tongji.edu.cn/info/1010/3067.htm) · [OBS-B02 求助表达](https://shtjh.tongji.edu.cn/info/1163/4216.htm)

### B-02｜回应一条求助

作为有相关经验的本校学生，我想在指定求助下给出建议或追问，以便发起者知道这条答复对应自己的问题并能继续沟通。

- Given：我已登录，并打开一条其他同学发布的「待回应」求助。
- When：我在该帖下提交第一条非空回复。
- Then：回复出现在该帖详情中，发起者重新打开可看到其内容和提交时间。该帖回复数变为 1，状态变为「已有回应」。

调研证据：[OBS-B01 朋辈答疑](https://youth.tongji.edu.cn/info/1010/3067.htm)

### B-03｜查看自己的求助进展

作为发过校园求助的学生，我想从自己的求助记录查看每条求助的状态和最近回应，以便判断应该继续等待、查看建议还是结束求助。

- Given：我有三条求助，分别是零回复、已有两条回复但问题未解决、以及我已确认解决。
- When：我打开自己的求助记录。
- Then：三条分别显示「待回应」「已有回应」「已解决」。已有两条回复的求助显示回复数 2 和最新回复时间，点开后能看到对应回复。

调研证据：[OBS-B03 进度和结果反馈](https://news.tongji.edu.cn/info/1002/6126.htm) · [OBS-B01 朋辈答疑与进展跟踪](https://youth.tongji.edu.cn/info/1010/3067.htm)

### B-04｜由发起者确认求助结果

作为已经解决问题的求助发起者，我想关闭自己的求助并记录解决方式，以便回应者和后续查看该帖的同学知道问题如何解决。

- Given：一条求助由我发起且处于「待回应」或「已有回应」，我已实际解决问题。
- When：我填写解决说明并确认「已解决」。
- Then：我的求助记录和帖子详情都显示「已解决」，详情显示解决说明和确认时间。其他普通学生尝试更新同一条求助时收到无权限提示，原状态保持不变。

调研证据：[OBS-B03 进度和结果反馈](https://news.tongji.edu.cn/info/1002/6126.htm) · [OBS-B04 实际认领结果](https://www.tongji.edu.cn/info/1033/13065.htm)

### B-05｜发布可供认领的拾到物品线索

作为在校园拾到物品的学生，我想发布让失主能辨认和联系认领的线索，以便失主按明确的地点或渠道取回物品。

- Given：我已登录，拾到一件物品，并已确认一个可用的交接或领取途径。
- When：我选择「失物招领」，填写物品类别、校区、大致地点、拾到日期、非敏感特征和领取途径后发布。
- Then：失物招领列表出现该条记录，其他同学可以看到所填线索和领取途径。发布表单无需填个人手机号、学号或证件号码。

调研证据：[OBS-B04 失物招领活动记录](https://www.tongji.edu.cn/info/1033/13065.htm) · [同济保卫处失物招领入口](https://baowei.tongji.edu.cn/3063/list.htm)
